## Calculation Notes

- **Disk write estimate** (theoretical): 400 samples/s × 2 sensors × 1 hour = 2,880,000 samples.
  Each row ≈ 40 bytes → ≈ 115 MB raw. SQLite WAL overhead: ~1.5×. Expected ≈ 170 MB.
- **Network TX estimate**: same sample count batched as JSON (~80 bytes/sample) → ≈ 230 MB.
  This is within Oracle Always Free (10 GB/month).
