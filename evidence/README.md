# Evidence Directory

This directory holds measured evidence generated during testing.
These files are **not committed** to the repo (see `.gitignore`) but must be
included in the submission zip via `git add -f` or by copying manually.

## Expected files

| File / Folder | Generated by |
|---|---|
| `resources_1h.csv` | `bash scripts/resources/measure_1h.sh <pid>` |
| `ramp_export.jsonl` | `pipeline export --session <id> --from device` (ramp mode run) |
| `01_process_kill/run.log` | `bash scripts/failure_tests/01_process_kill.sh` |
| `02_power_cut/` (status_before.json, status_after.json, losses.jsonl) | `scripts/failure_tests/02_power_cut_sim.md` |
| `03_network_cut/run.log` | `bash scripts/failure_tests/03_network_cut.sh` |
| `04_mock_restart/run.log` | `bash scripts/failure_tests/04_mock_restart.sh` |
| `05_disk_full/run.log` | `bash scripts/failure_tests/05_disk_full.sh` |
| `06_clock_change/run.log` | `bash scripts/failure_tests/06_clock_change.sh` |
| `07_corrupt_and_duplicate/run.log` | `bash scripts/failure_tests/07_corrupt_and_duplicate.sh` |
| `08_sensor_silent/run.log` | `bash scripts/failure_tests/08_sensor_silent.sh` |

## Adding evidence to git for submission

These files are excluded by `.gitignore`. To include them in a commit:

```bash
git add -f evidence/resources_1h.csv
git add -f evidence/ramp_export.jsonl
git add -f evidence/01_process_kill/
# etc.
```
